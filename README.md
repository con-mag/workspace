# المركز — نظام العمل والمعرفة

النسخة الحالية مبنية على أبسط مسار ممكن:

**المتصفح ← GitHub REST API ← مستودع GitHub**

لا يوجد Vercel أو API وسيط أو قاعدة بيانات خارجية.

## الإعداد

افتح `js/config.js` وضع توكن GitHub الخاص بالمستودع في `TOKEN`:

```js
window.GITHUB_CONFIG = Object.freeze({
  OWNER: "con-mag",
  REPO: "workspace",
  BRANCH: "main",
  TOKEN: "ضع_التوكن_هنا",
  ADMIN_PASSWORD: "1122"
});
```

التوكن المطلوب: Fine-grained Personal Access Token بصلاحية **Contents: Read and write** على مستودع `workspace`.

## ما تم إصلاحه

- إضافة العميل أصبحت تنشئ مجلد العميل الحقيقي في GitHub، مع ملف البيانات الخاص به.
- إضافة ملف أو مجلد تحفظ مباشرة في المسار الحالي.
- بعد الحفظ تُمسح ذاكرة المجلد ويعاد تحميله من GitHub، لذلك يظهر العنصر الجديد فورًا.
- تعديل ملفات النصوص يحفظ مباشرة في GitHub.
- تحديث SHA يُعاد جلبه تلقائيًا عند حدوث تعارض، ثم تعاد محاولة الحفظ.
- إعادة تسمية الملفات والمجلدات تعمل على كامل الشجرة.
- حذف الملفات والمجلدات يعمل بشكل متسلسل.
- حذف العميل يحذف مساحة العميل ومحتوياتها.
- تعديل بيانات العميل متاح من مكتبة العملاء.
- تعديل وحذف الإضافات في المشروعات والمعرفة والأفكار والمصادر متاحان.
- المزامنة بين الأجهزة تتم من GitHub مباشرة عبر polling.
- يوجد fallback محلي فقط إذا لم يُضبط التوكن.

## نشر GitHub Pages

هذه الحزمة نفسها هي محتوى الموقع الجاهز للنشر. ارفع الملفات والمجلدات الموجودة فيها إلى جذر مستودع `workspace`، بحيث يكون `index.html` و`js/` و`css/` في الجذر.

بعد وضع التوكن في `js/config.js` وإعادة تحميل الموقع، سيظهر النظام بوضع **مشترك** وتصبح عمليات الإضافة والتعديل والحذف على مستودع GitHub مباشرة. هذه النسخة أيضًا تتجاوز كاش طلبات القراءة، وتعيد جلب SHA عند التعارض، وتعرض سبب فشل GitHub بدل رسالة عامة.

إذا كان المتصفح يعرض نسخة قديمة بعد الرفع، أعد التحميل بـ `Ctrl + F5`؛ ملفات JavaScript تحمل رقم إصدار في عناوينها لتقليل مشكلة الكاش.


## ملاحظات الإصلاح في v15

- إصلاح تعارض اسم الدالة `localGet` الذي كان يجعل استرجاع حالة `localStorage` غير صحيح عند بدء التطبيق.
- تحسين اكتشاف التوكن: إزالة علامات الاقتباس/المسافات الزائدة وعدم اعتبار القيم الوهمية توكنًا صالحًا.
- منع كاش طلبات القراءة إلى GitHub حتى لا تبقى المزامنة على نسخة قديمة.
- إضافة تصنيف واضح لأخطاء 401/403/404/409/422 وأخطاء الاتصال لبيان السبب الحقيقي.
- إرسال Authorization عند جلب الملفات من `download_url`، وهو مهم خصوصًا للمستودعات الخاصة.
- زر حالة المزامنة أصبح ينفذ تحديثًا فعليًا بدل الاكتفاء برسالة.
- رفع إصدار ملفات JavaScript إلى v15 لتجنب كاش GitHub Pages.

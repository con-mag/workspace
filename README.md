# المركز — نظام العمل والمعرفة

## النسخة المحلية

هذه النسخة أعيد تنظيمها لتعمل **محليًا بالكامل على جهاز واحد**.

المسار الآن:

**المتصفح ← LocalStorage + IndexedDB**

ولا تعتمد على:
- GitHub API
- قاعدة بيانات خارجية
- مزامنة بين الأجهزة
- خادم أو API وسيط
- مكتبات JavaScript من CDN

### التخزين

- الإعدادات والبيانات المنظمة: `localStorage`.
- ملفات العملاء والمرفقات: `IndexedDB`.
- الملفات الموجودة في قالب العميل الأساسي تبقى جزءًا من المشروع نفسه.
- البيانات تبقى محفوظة بعد إغلاق التطبيق وإعادة فتحه.

### ما تم تنظيفه

- إزالة منطق GitHub بالكامل.
- إزالة polling والمزامنة والحالات المرتبطة بالاتصال.
- إزالة إعدادات وتوكنات GitHub.
- إزالة الاعتماد الخارجي على Google Fonts وMammoth CDN.
- تبسيط مسار الحفظ والتعديل والحذف.
- تحسين تنظيم حالات الملفات المحلية.
- جعل Light Mode هو الوضع الافتراضي.
- إزالة عناصر الواجهة التي كانت خاصة بالمزامنة.
- تحديث رسائل النظام لتوضح أن البيانات محلية.

### التشغيل

يمكن تشغيل المشروع كموقع ثابت. افتح `index.html` من بيئة محلية مناسبة أو عبر خادم ملفات محلي بسيط.

> ملاحظة: بعض المتصفحات قد تقيّد IndexedDB أو بعض ميزات الملفات عند فتح HTML مباشرةً عبر `file://`. إذا حدث ذلك، استخدم خادم ملفات محليًا فقط؛ هذا لا يعني إضافة أي خدمة خارجية.

### كلمة مرور التعديل

كلمة مرور التعديل محفوظة في `js/config.js` كإعداد محلي. غيّر قيمة `ADMIN_PASSWORD` قبل الاستخدام إذا أردت.

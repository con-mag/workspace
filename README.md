# المركز — نظام العمل والمعرفة

هذه النسخة تعمل بنموذج بسيط ومباشر:

**المتصفح ← GitHub REST API ← مستودع GitHub**

لا يوجد Vercel ولا API وسيط ولا قاعدة بيانات خارجية.

## الإعداد الوحيد

افتح:

`site/js/config.js`

وضع Fine-grained GitHub Personal Access Token في:

```js
TOKEN: "ضع_التوكن_هنا"
```

الإعدادات الحالية للمشروع:

```js
window.GITHUB_CONFIG = Object.freeze({
  OWNER: "con-mag",
  REPO: "workspace",
  BRANCH: "main",
  TOKEN: "ضع_التوكن_هنا",
  ADMIN_PASSWORD: "1122"
});
```

التوكن يحتاج إلى صلاحية **Contents: Read and write** على مستودع `workspace`.

## النتيجة

- إضافة عميل تنشئ مساحة GitHub حقيقية مع `.client.json` وملف `.keep`.
- إضافة مجلد تنشئ مجلدًا حقيقيًا.
- إضافة ملف تنشئ الملف في المسار الحالي أو المسار الذي تختاره.
- رفع الملفات الفعلية مدعوم ضمن الحد الحالي 4MB.
- تعديل TXT/MD وملفات النصوص الأخرى ثم حفظها مباشرة في GitHub.
- إعادة تسمية الملفات والمجلدات.
- حذف الملفات والمجلدات والعملاء مع الحذف المتسلسل للمحتوى.
- تعديل بيانات العملاء.
- تعديل وحذف الإضافات في المعرفة والأفكار والمشروعات والمصادر.
- معالجة تعارض SHA تلقائيًا عند تحديث الملفات.
- مزامنة دورية بين الأجهزة عبر GitHub.
- لا توجد جلسة خادمية؛ كلمة المرور 1122 مجرد بوابة واجهة محلية، بينما صلاحية الكتابة الفعلية تأتي من التوكن.

## النشر على GitHub Pages

انشر محتويات مجلد `site/` في المكان الذي تخدم منه GitHub Pages، ثم افتح الموقع.

بعد وضع التوكن في `site/js/config.js` سيعمل الحفظ المشترك مباشرة من المتصفح.
